# Мерей той · 70 жас — сайт-приглашение

Статический сайт: открой `index.html`, и он работает. Сборка не нужна.

## Файлы
| Файл | Что это |
|---|---|
| `index.html` | Приглашение (все стили и скрипты внутри) |
| `father.jpg` | Фото юбиляра. Замени на версию в шапане, имя файла оставь тем же |
| `music.mp3` | **Положи сам.** Фоновая музыка; пока файла нет, кнопка музыки просто скрыта |
| `og.jpg` | Превью ссылки в WhatsApp/Telegram (1200×630) |
| `link.html` | Генератор персональных ссылок «Құрметті Асан аға!» + QR |
| `apps-script.gs` | Код для Google Таблицы (ответы гостей) |
| `nginx.conf`, `Dockerfile` | Если выкладываешь на свой сервер |

## 1. Подключи ответы гостей и стену тілектер

### Вариант А: Google Форма (можно с телефона, без кода)
1. forms.google.com → новая форма. 5 вопросов, тип «Текст (строка)», все необязательные, по порядку:
   Аты-жөні · Жауабы · Адам саны · Тілегі · Сілтеме
2. Настройки → Ответы: выключить «Ограничить одним ответом» и обязательный вход в аккаунт.
3. Вкладка «Ответы» → «Связать с Таблицами» → создать.
4. В таблице: «Настройки доступа» → «Все, у кого есть ссылка» → «Читатель» (нужно для стены тілектер; телефонов в таблице нет).
5. Отправь ссылку на форму и на таблицу — коды полей вписываются в `CONFIG.FORM_URL`, `CONFIG.FORM_FIELDS`, `CONFIG.SHEET_ID`.

### Вариант Б: Google Apps Script (с компьютера)
1. Открой `apps-script.gs`, там пошаговая инструкция в шапке (5 минут).
2. Полученный URL вставь в `index.html` → `CONFIG.SCRIPT_URL`. Стена тілектер подтянется сама.
3. На листе «Қорытынды» видно, сколько всего придёт людей. Telegram-уведомления: TG_TOKEN, TG_CHAT.

Пока ничего не подключено, форма работает «вхолостую»: гость видит «Рақмет!», свой тілек видит только он сам.

## Фотоальбом
Положи фото рядом с `index.html` (например `p1.jpg`, `p2.jpg` …, вертикальные 3:4, до 300 КБ каждое)
и впиши их в `CONFIG.PHOTOS: ["p1.jpg","p2.jpg"]`. Пока список пустой, раздел скрыт.

## 2. Выложи сайт

### Вариант А: Vercel (бесплатно, 3 минуты)
1. Залей папку в репозиторий GitHub (или перетащи папку на vercel.com/new → «Deploy»).
2. Получишь адрес вида `daulet70.vercel.app`.
3. В Settings → Domains можно позже привязать свой домен.

### Вариант Б: свой сервер (nginx в Docker)
```bash
docker build -t merei-toi .
docker run -d --name merei-toi --restart unless-stopped -p 8080:80 merei-toi
```
Дальше проксируй домен на `:8080` и выпусти SSL: `sudo certbot --nginx -d DOMAIN`.
Без Docker: скопируй файлы в `/var/www/merei-toi`, возьми `nginx.conf`, замени `DOMAIN` и запусти certbot.

## 3. После выбора адреса
- В `index.html` замени `<meta property="og:image" content="og.jpg">` на полный адрес: `https://ТВОЙ-ДОМЕН/og.jpg`.
  WhatsApp показывает картинку только по полной ссылке.
- В `CONFIG.SITE_URL` впиши `https://ТВОЙ-ДОМЕН/`.
- Открой `https://ТВОЙ-ДОМЕН/link.html`, вводи имена гостей и отправляй персональные ссылки.

## 4. Проверка перед рассылкой
- Открой ссылку на телефоне (iPhone и Android): конверт → «Шақыруды ашу» → музыка играет.
- Кнопка «Карта арқылы ашу»: 2GIS, Google Maps и Яндекс открывают «Millennium».
- «Күнтізбеге қосу» добавляет событие 09.01.2027 16:00.
- Отправь ссылку себе в WhatsApp и проверь, что появилась карточка с фото.
